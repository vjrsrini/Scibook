# 🔬 SciBook Frontend Client

The frontend client for **SciBook** — Built with React 19, Vite, React Router v7, Lucide Icons, and Socket.IO-Client.

---

## ✅ Completed Frontend Features

- [x] **Authentication Flow**: Login, Registration, Auth Context, token storage, and one-click demo login buttons.
- [x] **Dashboard Overview**: Live analytics counter cards (Total Instruments, Active Bookings, Pending Approvals, Maintenance count) and live booking feed.
- [x] **Instrument Catalog**: Filter instruments by category, real-time search, status badges (`available`, `in-use`, `maintenance`, `offline`), and reservation modal trigger.
- [x] **My Bookings & Admin Approvals**: View reservations, status badges, cancel booking action, and one-click operator approve/reject queue.
- [x] **User Directory**: Admin interface to modify user roles and update lab certification levels.
- [x] **Real-Time Live Sync**: Socket.IO integration for instant multi-user UI updates without page reloads.
- [x] **Custom Glassmorphism UI**: High-end sci-tech dark theme design system in `index.css`.
